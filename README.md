# CodeAlpha Python Programming Internship Projects

This repository contains four beginner-friendly Python console projects based on the CodeAlpha task instructions.

## Projects
1. **Hangman Game** — random word selection, loops, strings, and input validation.
2. **Stock Portfolio Tracker** — dictionaries, calculations, and optional CSV report saving.
3. **JPG File Organizer** — file and folder handling with `pathlib` and `shutil`.
4. **Basic Chatbot** — functions, loops, and conditional responses.

## Requirements
- Python 3.9 or later recommended
- No third-party packages are required

## How to run
Open a terminal in this folder and run one script at a time:

```bash
python Task1_Hangman_Game.py
python Task2_Stock_Portfolio_Tracker.py
python Task3_JPG_File_Organizer.py
python Task4_Basic_Chatbot.py
```

On some systems, use `python3` instead of `python`.

## Important notes
- The stock prices are hardcoded sample values, not live market prices.
- The file organizer moves JPG/JPEG files. Test it first with a sample folder, and double-check the source and destination paths before running it.
- Each script can run independently.

## Suggested GitHub repository name
Create a repository named `CodeAlpha_Python_Programming` or use the required `CodeAlpha_ProjectName` pattern for each individual project.
